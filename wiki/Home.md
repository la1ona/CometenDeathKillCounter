# CometenDeathKillCounter

CometenDeathKillCounter is a customizable death and kill counter for Streamer.bot and OBS Studio.

Current release: **v1.11.0**

License: **MIT**

## Features

- Stream Deaths and Stream Kills
- Lifetime Total Deaths and Total Kills
- Independent visibility controls
- Movable and scalable OBS browser overlay
- Custom title, colors, width, scale and background opacity
- Persistent Streamer.bot global variables
- Chat-command support
- Stream Deck-friendly operations
- Local WebAdmin panel

## Quick start

1. Follow the [Installation](Installation) guide.
2. Create the Streamer.bot action `Cometen Death Counter`.
3. Add the OBS browser overlay.
4. Open the WebAdmin panel.
5. Add optional chat commands or Stream Deck controls.
