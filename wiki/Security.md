# Security

CometenDeathKillCounter is designed for local Streamer.bot and OBS use.

## Do not publish

- private LAN details from a production setup
- usernames or absolute user-profile paths
- Streamer.bot authentication secrets
- OBS WebSocket passwords
- API keys, platform tokens or webhook URLs

The default `127.0.0.1` address is localhost and is safe to publish.

Do not expose the Streamer.bot WebSocket directly to the public Internet.

See the maintained [SECURITY.md](https://github.com/la1ona/CometenDeathKillCounter/blob/main/SECURITY.md) for the repository security policy.
